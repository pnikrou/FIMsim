# requires teehr==0.5.0, TEEHR pins zarr<3 / s3fs<2026 / fsspec<2026, and FIMsim
# runs on zarr 3 / s3fs 2026, so no resolver can satisfy both.  --no-deps leaves
# the conda-installed stack alone, which is the combination that was verified.
#
# Every line is pinned and nothing is resolved, so pip installs exactly these
# versions and pulls in nothing else.  Do NOT list a package here that conda
# already provides in environment.yml: an explicit pin replaces the conda copy
# (this file once pinned pytz and quietly downgraded the one pandas uses).
# Run `python -m core.deps` after any change.
#
# Needs: git on PATH (three packages install from GitHub), and about 400 MB of
# download for pyspark, which has no wheel and installs from source.
