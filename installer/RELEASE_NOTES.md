## FIMsim @TAG@ — Flood Inundation Model Simulation Tool

### Download

| Your computer | Download | Then |
|---|---|---|
| **Windows 10 / 11** | `FIMsim-setup-windows.exe` | Double-click it and follow the steps. No administrator password needed. |
| **Mac** (Apple Silicon or Intel) | `FIMsim-mac.dmg` | Drag FIMsim into Applications, then open it. |

### First start — one time only
The first time FIMsim starts, it sets itself up in a window that stays open:
it downloads and installs the scientific packages it needs (GDAL, rasterio, ARC-Curve2Flood, OWP HAND-FIM, …).
It needs an internet connection, downloads about 1.5 GB, uses about 3 GB of disk and takes about 5–20 minutes.
FIMsim then opens by itself, and from then on it opens immediately.
You do not need Python, conda or a terminal.

### macOS: the first time you open it
FIMsim is not signed with a paid Apple developer account, so macOS asks you to confirm.
Right-click FIMsim → **Open** → **Open**. On macOS 15 or newer, if there is no Open button, go to
System Settings → Privacy & Security, scroll down and click **Open Anyway**.

### Windows: the first time you run it
Windows SmartScreen may say "Windows protected your PC". Click **More info** → **Run anyway**.
