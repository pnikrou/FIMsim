# FIMsim is NOT installed with `pip install -r requirements.txt`.
#
# It needs two steps, and pip alone cannot do either of them:
#
#     conda env create -f environment.yml
#     conda activate FIMsim
#     python -m core.deps --fix
#     python -m core.deps
#
# Why: fimserve requires teehr==0.5.0, and TEEHR pins zarr<3 / s3fs<2026, while
# FIMsim runs on zarr 3 / s3fs 2026.  No pip resolver can satisfy both.  It
# either deadlocks (pip backtracks through dozens of old fimserve releases and
# downloads a 450 MB pyspark tarball first) or "succeeds" by downgrading zarr
# and s3fs, which breaks every NWM download.  Also, the geospatial stack
# (GDAL, PROJ, rasterio, geopandas) needs conda to share one GDAL build.
#
# The line below is deliberately not a valid requirement, so that pip stops here
# and prints this instruction instead of building a broken environment.
USE-environment.yml-AND-core.deps---SEE-README-INSTALL-SECTION-NOT-PIP
